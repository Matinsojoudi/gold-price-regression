# پیش‌بینی قیمت طلا با رگرسیون خطی و ریج
تمرین اول درس یادگیری عمیق - دانشگاه ارومیه  
**دانشجو:** متین سجودی (۱۴۰۱۴۴۲۱۰۲۵)  
**استاد:** دکتر صالح یوسفی  

---

### شرح مختصر
در این پروژه، قیمت پایانی روز بعد صندوق طلای SPDR (نماد GLD) با استفاده از داده‌های معاملاتی سال‌های ۲۰۱۸ تا ۲۰۲۴ با دو مدل Linear Regression و Ridge Regression پیش‌بینی شده است.

### نتایج ارزیابی روی داده‌های تست:
* **Linear Regression:**
  * MAE: 1.4745 دلار
  * RMSE: 1.9759 دلار
  * $R^2$: 0.9938
* **Ridge Regression ($\alpha=1.0$):**
  * MAE: 1.4745 دلار
  * RMSE: 1.9757 دلار
  * $R^2$: 0.9938

python gold_price_regression.py
